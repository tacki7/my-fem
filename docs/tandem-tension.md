# タンデム冷間圧延のスタンド間張力（動特性）計算

`tools/tandem_tension.py` — 参考書 5.4 節「冷間圧延の動的連続圧延理論」の
(5.37)〜(5.52) 式を実装したスクリプト。FEM 本体とは独立した Python スクリプト
（numpy / matplotlib のみ使用）。

```bash
python3 tools/tandem_tension.py --self-test            # 検証 12 項目（約 70 秒）
python3 tools/tandem_tension.py --case all --plot      # 図 5.16〜5.27 の 6 ケース（約 10 秒）
python3 tools/tandem_tension.py --case entry --model-compare   # 張力モデル 3 種の比較
python3 tools/tandem_tension.py --case entry --tension-control # 張力 PI 制御あり
python3 tools/tandem_tension.py --sensitivity --case none      # 定常点まわりの感度
```

図と CSV は `tools/out/`（`.gitignore` 済み）に出る。

## 本文との対応

| 本文 | 実装 |
|---|---|
| (5.37) `h = S + P/M` | `solve_exit_thickness`（二分法で保護した Newton 法） |
| (5.38) 荷重式 | Hill の式 + Hitchcock の扁平（本文の注記どおり） |
| (5.39)〜(5.43) 先進率・後進率 | Bland & Ford の中立点から先進率、後進率は (5.41) |
| (5.44)(5.45) 最も単純化したモデル | `--model simple`（張力を状態量として積分） |
| (5.46)〜(5.49) 板厚分布を考慮したモデル | `--model dist`（全張力 T を積分、スタンド間の板厚分布からばね定数を直列合成） |
| (5.50)〜(5.52) スタンド間剛体モデル | `--model rigid`（既定。5.4.2 節の計算例と同じ） |
| 図 5.11 スタンド間の板厚分布 | `StripQueue`（可変長スライス列。搬送遅れも兼ねる） |
| 図 5.13 フローチャート | `Simulator.step`（外乱 → 圧下・ASR → 板厚・張力 → 搬送） |
| 図 5.14 / 5.15 ASR・圧下位置制御 | `--asr-tau` / `--screwdown-dyn`（計算例では考慮しないので既定は無効） |
| 表 5.5 ドラフトスケジュール | `Mill` の既定値 |

rigid モデルでは未知数 h₁…h₅, q_f1…q_f4 の 9 元連立非線形方程式（ゲージメータ式 5 本 +
スタンド間の速度一致 4 本）を毎ステップ Newton 法で解く。本文 122 ページの「出口板厚の
計算を行う時に Newton-Raphson 法を適用する必要がある」に当たる部分。

## 検証結果

測定条件: 既定値（上表）、rigid は dt = 2 ms、simple / dist は dt = 0.5 ms、計算時間 8 s。

`--self-test` の 12 項目はすべて PASS:

- 初期設定の往復（S → h）誤差 0、定常の体積速度のばらつき 0
- 外乱なしで 3 モデルとも |Δh| < 3e-12 mm、|Δq_f| < 6e-10 kgf/mm² でドリフトしない
- 弾性モデル (1)(2) の最終値が剛体モデル (3) と一致（Δh の差 < 1e-6 mm）。
  3 つの別実装が定常で一致するので、相互の検算になっている
- dt を半分にしても最終値が変わらない（rigid 3e-11 mm、simple 3e-7 kgf/mm²）
- 圧下・ASR 動特性を入れても最終値は同じ（差 2.6e-4 mm）
- 張力 PI 制御で張力偏差 1.395 → 0.061 kgf/mm²

過渡の違い（素材板厚 +5% 直後の Δq_f1）: rigid は瞬時に −0.456、simple は時定数約 8 ms で
追従、dist は T を状態量に持つので板厚が増えた瞬間に応力が下がり、simple より速く立ち上がる。

### 本文の結論 (1)〜(6) との照合

6 ケースとも、本文 122〜124 ページに書かれた結論の向きをすべて再現した（計 20 項目）。

| ケース | 本文の結論 | 計算（最終値） |
|---|---|---|
| 素材板厚 +5% | 板厚は各スタンドで増加、張力は減少 | Δh = +0.055…+0.017 mm、Δq_f = −1.40…−0.81 |
| #1 圧下 +5% | 板厚は全スタンド増加、張力は減少 | Δh₁ = +0.067、Δh₅ = +0.019 mm |
| #5 圧下 +5% | Δq_f4 増、Δh₄ 減、Δh₅ は最終的にあまり変わらない | Δq_f4 = +2.22、Δh₄ = −0.0069、Δh₅ +0.0079 → +0.0025 mm |
| #1 速度 +1% | Δq_f1 減、Δh₁ 増、Δh₅ 増 | Δq_f1 = −0.80、Δh₅ = +0.0069 mm |
| #3 速度 +1% | Δq_f3 減、Δq_f2 増、Δh₅ はほとんど変わらない | Δq_f2 = +1.41、Δq_f3 = −0.56、Δh₅ = −0.0001 mm |
| #5 速度 +1% | Δq_f4 増、Δh₅ 減、Δh₄ 減 | Δq_f4 = +2.09、Δh₅ = −0.010 mm |

図から読み取った値との比（計算 / 図）はおおむね 0.7〜1.8。R・M・μ・L が本文に無いので
数値の一致までは期待できない。時刻は板厚変化の #2 到達 1.45 s が一致し、#5 到達は
4.25 s（図では約 4.8 s）。

## 限界

- rigid モデルはスタンド間の材料を剛体とみなすので、スタンド間で板厚分布が変わる過渡中は
  スタンド間の質量収支が厳密には合わない（本文 (3) の考え方そのものの近似）
- ASR は 1 次遅れだけ。図 5.14 のモータ・サイリスタ・drooping までは入れていない
- 張力 PI 制御（`--tension-control`）は本文の範囲外の追加。上流スタンドのロール速度を
  操作する最小構成で、#5 を速度基準にしている
- 時定数の短い弾性モデルは陽解法なので dt は 1 ms 以下にすること
